## 📱 完整使用流程

### 电脑端使用

1. **启动服务器**
   - 双击 `启动服务器.command`
   - 或在终端运行 `./start-server.sh`

2. **访问应用**
   - 浏览器会自动打开
   - 或手动访问：http://localhost:8080

3. **使用完毕后关闭**
   - 双击 `关闭服务器.command`
   - 或在终端运行 `./stop-server.sh`

### 手机端使用

1. **启动服务器**（在电脑上）
   - 双击 `启动服务器.command`

2. **获取访问地址**
   - 启动后会显示手机访问地址
   - 如：http://192.168.0.118:8080

3. **手机访问**
   - 确保手机和电脑在同一WiFi
   - 方式1：扫描二维码（访问 http://localhost:8080/qrcode.html）
   - 方式2：直接输入地址

4. **添加到主屏幕**（可选）
   - iOS：点击分享按钮 → "添加到主屏幕"
   - Android：菜单 → "添加到主屏幕"

## 🆘 常见问题

### Q1: 双击.command文件没反应？
**解决方法：**
1. 右键点击文件
2. 选择"打开方式" → "终端"
3. 或者右键 → "打开" → 确认"打开"

### Q2: 提示"无法验证开发者"？
**解决方法：**
1. 打开"系统偏好设置" → "安全性与隐私"
2. 点击"仍要打开"
3. 或右键文件 → 按住Option键 → 选择"打开"

### Q3: 如何知道服务器是否在运行？
**方法：**
- 双击 `检查服务器状态.command`
- 或访问 http://localhost:8080 看是否能打开

### Q4: 忘记关闭服务器怎么办？
**解决方法：**
- 双击 `关闭服务器.command`
- 或重启电脑会自动关闭

### Q5: 手机无法访问？
**检查清单：**
- ✅ 服务器是否已启动？
- ✅ 手机和电脑是否在同一WiFi？
- ✅ 输入的IP地址是否正确？
- ✅ 防火墙是否允许连接？

## 🔧 高级技巧

### 自定义端口
如果8080端口被占用，可以修改端口：

1. 右键 `start-server.sh` → 打开方式 → 文本编辑
2. 找到 `8080` 改为其他端口（如 `8888`）
3. 保存

### 仅本机访问（更安全）
如果不需要手机访问：

1. 编辑 `start-server.sh`
2. 找到 `python3 -m http.server 8080`
3. 改为 `python3 -m http.server 8080 --bind 127.0.0.1`
4. 保存

这样只能在电脑上访问，更安全。
